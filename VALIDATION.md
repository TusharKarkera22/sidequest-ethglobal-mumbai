# Validation

Run the publication scan, automated tests, type-check, ESLint and production build using the commands in README.

Automated checks cover validation, lifecycle transitions, expiration, cookie isolation, public-identity non-disclosure, concurrent practice claims, live-record provenance, deterministic claims, rejected wallet requests and provider retention.

Runtime verification should exercise create/find/claim/complete in an isolated practice session. For live integration evidence, publish a fresh task to the public-edition namespace and verify its readback. No historical user wallet or transaction evidence is included here.
