# Sidequest — 2 minute 30 second walkthrough

Record the application itself with a screen recorder. Show the mode selector clearly; never describe practice samples as onchain transactions.

**0:00–0:20 — The problem**

“Every hackathon has the same problem: the person who could unblock you is somewhere in the room, while your ask gets lost in chat. Sidequest is a public noticeboard for small pieces of work. Ask clearly, find by skill, and keep stale requests off the board.”

**0:20–0:55 — Find and claim**

Start on Practice. Search “wallet”, open “Make wallet onboarding feel effortless”, and click “I can help”. Explain that the backend saves the claim. Click “Mark complete”, close the dialog and select Completed. Show the record survived refresh.

**0:55–1:20 — Post a task**

Post “Review our three-minute demo”. Describe the requested feedback and add a contact handle. Choose Community, Pitching and a one-hour expiry. Show the new task in My activity. Explain that bounty offers are not escrowed.

**1:20–2:00 — Prove the Arkiv integration**

Switch to Arkiv testnet. Connect your own funded Rabdi wallet, create a fresh task and show the signature. Open its explorer link, then refresh to show the backend reading it from Arkiv. If the wallet is not funded yet, state that clearly and show the actual empty live query plus the SDK integration; do not call this a completed onchain demo.

**2:00–2:20 — Why Arkiv**

“Tasks and claims are wallet-owned records. Other applications can query the same board without our backend. Expiration is built into the database, so a request has a useful lifetime. Separate claim records let another builder act without editing the publisher’s data.”

**2:20–2:30 — Close**

“Sidequest turns a room full of builders into a useful network of small asks. Next: wallet notifications, better discovery and an agent client using the same public schema.”

## Recording checklist

- Live record and explorer proof visible for the Arkiv submission.
- No private keys, wallet recovery phrases, access credentials or personal browser tabs on screen.
- Keep under three minutes; export an MP4 and attach it in the ETHGlobal project submission.
- Include the demo URL, accessible code, public writer address and transaction link.
